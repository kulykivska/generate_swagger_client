# Security Policy

## Supported versions

This repository is kept for reference and is not actively maintained. Its dependencies are outdated and it should not be used in production. Reports are still welcome, but fixes may not be released.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the affected file or version, steps to reproduce and the impact you expect.

You should get a reply within 7 days. Once a fix is available, the report will be disclosed with credit to you unless you ask otherwise.
